03 Перша програма та змінні


    

      

        
Привіт, світ!

        

          Функція print() виводить текст на екран, а
          input() читає те, що ввів користувач. Рядки
          тексту беруть у лапки, а коментарі починаються зі знака
          # — Python їх ігнорує.
        

        

          Змінна — це підписана «коробка», у яку
          кладуть значення. У прикладі змінна name зберігає
          ім’я, а age — число.
        

      

      
    


    
Основні типи даних

    

      
int
ціле число
42, -7, 0

      
float
дробове число
3.14, 2.5e3

      
str
рядок тексту
"Київ"

      
bool
логічне значення
True, False

      
list
список
[1, 2, 3]

      
dict
словник
{"ua": 380}

    


    

      
      

        
Умови: квадратне рівняння

        

          Розв’яжемо рівняння ax2 + bx + c = 0.
          Спочатку обчислюємо дискримінант:
        

        
D = b2 − 4ac

        
Якщо D > 0, рівняння має два корені:

        
x1,2 = (−b ± √D) / 2a

        

          У Python степінь записують двома зірочками: b ** 2,
          а розгалуження — словами if, elif
          і else. Відступи обов’язкові! Саме
          чотири пробіли показують, які рядки належать до умови.
        

      

    

  


  
  

    
04 Цикли та функції

    

      

        
Цикл for наживо

        

          Цикл повторює дію потрібну кількість разів. Функція
          range(n) видає числа від 0 до
          n − 1. Пересуньте повзунок —
          і програма праворуч «виконається» знову.

Власні функції

        

          Функцію оголошують словом def. Вона отримує
          аргументи, щось обчислює і повертає результат через
          return. Один раз написана функція може
          викликатися скільки завгодно разів.
        

        

          Зверніть увагу: 20! ≈ 2,43·1018, а Python
          спокійно працює з такими числами — цілі числа в ньому
          не мають верхньої межі, на відміну від багатьох інших мов.
