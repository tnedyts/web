# Світ штучного інтелекту — лабораторні роботи 4–9

Один сайт на тему штучного інтелекту, який розвивається від лабораторної до лабораторної.
Кожна папка — окремий самодостатній стан сайту на момент здачі відповідної роботи.

## Що треба замінити своїми даними

* **ПІБ і група** — заглушки «Прізвище Ім'я По батькові» та «група ____» на сторінках автора й у колонтитулах.
* **Лаб. 9, карта** — зараз мітка стоїть на корпусі НУХТ (Київ, вул. Володимирська, 68). Якщо потрібне інше місце (дім, ваш корпус, кафе), замініть адресу в параметрах `q=`/`daddr=` у `lab9/media.html`. Щоб розставити кілька власних міток і змінити стиль карти, створіть карту в Google My Maps і вставте її код `<iframe>`.
* **Лаб. 9, відео** — завдання вимагає відредагувати відео засобами YouTube Studio (нарізка, звук, субтитри). Це треба зробити у своєму акаунті, а потім замінити ID відео (`aircAruvnKk`) у `lab9/media.html` на ID свого ролика.

## Дизайн

Один стиль для всіх лабораторних: мотив «матриці ваг» нейромережі (клітинки в кобальтово-малиновій палітрі),
холодний світлий фон і глибокий індиго. Шрифти — Unbounded (заголовки) та Onest (текст), обидва з повною
підтримкою кирилиці; файли шрифтів лежать у папці `fonts/` кожної лабораторної, тож сайт працює й без інтернету.

* Лаб. 8: рівно 4 кольори (`#F2F3F8`, `#16173A`, `#3B4BF5`, `#F2496B`) і 2 шрифти; HTML (XHTML 1.0 Strict) і CSS проходять валідацію W3C.
* Лаб. 6: у `<frameset>` використано атрибути `border`/`frameborder`/`framespacing` з теоретичної частини — вони прибирають рамки між фреймами, але не входять у суворий стандарт XHTML, тому валідатор позначає лише їх.

## Перегляд

Сторінки відкриваються локально (подвійний клік по `index.html`) або через GitHub Pages.
Музика «Нейронні сни» та всі зображення створені програмно спеціально для цього сайту.
